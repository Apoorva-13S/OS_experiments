# Experiment 1 – Basic Linux Commands

## Aim
To study and execute basic Linux commands for file management, directory navigation, text processing, input/output redirection, and process management.

## Topics Covered

1. Directory and File Operations – pwd, cd, mkdir, rmdir, ls, touch, cp, mv, rm, cat, head, tail.

2. I/O Redirection and Streams – stdin, stdout, stderr, >, >>, 2>, &>, <.

3. Pipes and Utilities – pipe (|), sort, uniq, tee, xargs.

4. Pattern Searching and File Finding – grep, find and their commonly used options.

5. Terminal Text Editors – Basic editing and navigation using Vim and Nano.

6. Process Management – jobs, bg, fg, ps, kill, nice, renice, top.
